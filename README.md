## ⚙️ Local Development Setup

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/ajunaid05/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Create .env file from template
cp .env.example .env

# 4. Start local development server
npm run dev
```

The application will launch locally at `http://localhost:5173`.

---

## 📦 Building for Production

To compile the optimized production bundle for Netlify / Vercel deployment:

```bash
npm run build
```

Output static files will be generated in the `/dist` directory ready for deployment.
